# Support

## Community support

- Use GitHub Discussions for setup questions, usage help, and design ideas.
- Use GitHub Issues for reproducible bugs and accepted feature work.
- Use private vulnerability reporting for security concerns.

Before asking for help, review the README, `docs/`, existing issues, API logs,
and worker logs. Include sanitized versions, configuration shape, deployment
method, exact commands, and error messages. Never post `.env`, OAuth tokens,
email bodies, customer data, or signed media URLs.

Community support is best-effort and has no response-time guarantee. Managed
hosting and commercial support, when offered, are separate from the AGPL license
and do not change the rights granted to the open-source code.
